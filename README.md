# Insecure Website Club

A directory of websites that support HTTP *sans* S. *It's okay to be a little insecure!*

Live at [insecure.club](http://insecure.club/) where you can [submit a website](http://insecure.club/submit). You could submit a PR instead *I guess* — add it to `sites.yaml` — but I prefer you use the form.

Anything else, shoot me an email: git-reply@insecure.club
